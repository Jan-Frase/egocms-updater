# Parallel Computing and I/O

The group Parallel Computing and I/O (ParCIO) conducts research and development on parallel systems. We develop concepts
for high-performance computing, storage and file systems, as well as for parallel programming. As part of our teaching
activities, we cover these topics and more regarding the efficient use of modern computer systems. We focus on the
following research areas:

- High Performance Computing
- Storage and File Systems
- Data Reduction Techniques
- I/O Interfaces
- Programming Concepts

For more information, please see our [research page](https://www.parcio.ovgu.de/Research.html).
